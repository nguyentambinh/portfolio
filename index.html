Giới thiệu

Mình học ngành Kỹ thuật phần mềm tại Viện Công nghệ số, Đại học Thủ Dầu Một, lớp D23KTPM01. Phần lớn thời gian mình dành cho các dự án nhóm: từ phân tích yêu cầu, thiết kế kiến trúc, viết code tới triển khai lên máy chủ và viết báo cáo.

Mình thích những bài toán có ràng buộc thật: mạng nhà sau CGNAT, máy chủ chỉ có 512 MB RAM cho cơ sở dữ liệu, mô hình học máy chạy hoàn toàn bằng CPU. Giải được những ràng buộc đó là phần mình thấy vui nhất.

Dự án

01

TBT Cloud

Nền tảng đám mây phân tán cung cấp máy chủ ảo từ máy tính cá nhân: Proxmox VE trên nhiều máy, mạng WireGuard, Control API FastAPI, web Flutter, tính tiền theo giờ, nạp tiền qua payOS, IPv6 riêng cho từng VPS.

  • Proxmox VE
  • FastAPI
  • Flutter Web
  • WireGuard
02

Hệ thống quản lý Đoàn – Hội

Web và ứng dụng Android quản lý báo cáo, kế hoạch, cán bộ cho Đoàn trường, có AI phân tích tài liệu, sơ đồ cán bộ 2D/3D, chạy trên VPS qua Cloudflare Tunnel.

  • Flutter
  • Supabase
  • PostgreSQL
  • Docker
03

Phát hiện lỗ hổng bằng LLM và GNN

Phát hiện lỗ hổng bảo mật trong mã nguồn năm ngôn ngữ: đồ thị CPG từ Joern, embedding UniXcoder, mạng nơ-ron đồ thị, Qwen2.5-Coder và mô hình xếp chồng, có app demo giải thích kết quả.

  • PyTorch Geometric
  • Joern
  • LLM
04

Insurance Microservices

Hệ thống bảo hiểm theo kiến trúc microservices: .NET, RabbitMQ, Elasticsearch, Eureka, triển khai Docker Compose trên VPS, kiểm chứng hiệu suất bằng k6.

  • .NET
  • RabbitMQ
  • Docker
  • k6
05

Quản lý nhân sự và tài chính

Ứng dụng Android quản lý nhân sự, chấm công, lương và tài chính doanh nghiệp, nâng cấp lên Flutter với các dịch vụ dart_frog tách theo khu vực.

  • Android Java
  • SQLite
  • Flutter
