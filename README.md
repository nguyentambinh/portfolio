# Portfolio · Nguyễn Tâm Bình

Trang giới thiệu cá nhân dạng tĩnh: HTML, CSS, JavaScript thuần, không cần build.

- Có giao diện sáng và tối (theo hệ thống, đổi được bằng nút ◐).
- Lọc dự án theo nhóm: đám mây, web, học máy, di động.
- `index.html` nằm ở gốc nên mọi máy chủ web tĩnh (nginx, GitHub Pages) phục vụ được ngay.

Chạy thử trên máy: mở `index.html` bằng trình duyệt, hoặc `python -m http.server 8000` rồi vào http://localhost:8000.
